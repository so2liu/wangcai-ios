# 月余 PRD

## 1. 产品概述

### 1.1 产品名称

- 中文名：月余
- 英文代号：WorthSnap
- 首发语言：简体中文
- 首发地区：面向中文用户，默认本位币 CNY

### 1.2 产品定位

月余是一款本地优先、隐私友好的 iOS 资产快照 App。用户每月按账户级别手动记录各类资产和负债现值，形成月度资产负债快照，并长期追踪总资产、总负债、净资产及资产结构变化。

月余不是流水型记账软件，也不是投资分析或理财建议工具。它关注的是低频、低压力、可长期坚持的家庭或个人净资产盘点。

### 1.3 核心价值

- 每月一次，降低记录压力。
- 按账户清单逐项确认，减少遗漏。
- 通过快照追踪长期净资产变化。
- 数据本地优先，并通过 iCloud 私有同步，产品方不接触用户资产数据。
- 不连接银行、券商或支付账户，不采集用户交易流水。

## 2. 版本策略

### 2.1 V1.0

V1.0 聚焦单人使用体验：

- 单个主账本。
- 本地存储。
- iCloud 私有同步。
- 账户级月度快照。
- 多币种与自动汇率。
- 净资产、总资产、总负债和趋势统计。
- Face ID 隐私锁。
- CSV/JSON 导出。

V1.0 不做真实家庭协作，但数据模型为后续协作预留账户归属和 owner 概念。

### 2.2 V1.1

V1.1 规划支持基于 CloudKit Sharing 的家庭协作：

- 邀请伴侣或家庭成员加入同一账本。
- 所有成员可查看所有账户和快照。
- 只有账户 owner 可编辑该账户金额。
- 共同账户的任意 owner 可编辑。
- 成员管理和基础权限控制。

### 2.3 V2 及以后

根据真实使用反馈评估：

- 更多导出格式。
- 更丰富的筛选和图表。
- 多账本。
- 数据导入。
- 更完整的家庭协作权限。

## 3. 非目标

以下能力不属于当前产品方向，V1.0 不做，未来也默认不作为核心方向：

- 银行、券商、支付账户自动同步。
- 流水记账。
- 预算管理。
- 发票或账单识别。
- 投资收益分析。
- 理财建议。
- 社区功能。
- 自建账号系统。
- 房产、车辆等主观估值资产。

## 4. 核心概念

### 4.1 账本 Ledger

账本是资产快照的容器。V1.0 只支持一个主账本。

字段建议：

- `id`
- `name`
- `baseCurrency`，默认 `CNY`
- `createdAt`
- `updatedAt`

V1.0 UI 不提供多账本切换，但数据结构可以预留 `ledgerId`。

### 4.2 账户 Account

账户是每个月需要单独填写和追踪的资产或负债项目。

示例：

- 招商银行尾号 4344
- 华泰证券
- 支付宝余额
- 房贷 - 建行
- 招商信用卡

账户字段建议：

- `id`
- `ledgerId`
- `name`
- `direction`：`asset` 或 `liability`
- `type`
- `currency`
- `ownership`
- `tags`
- `sortOrder`
- `archived`
- `createdAt`
- `updatedAt`

### 4.3 账户方向 Direction

账户方向用于计算总资产、总负债和净资产。

- 资产账户：计入总资产。
- 负债账户：计入总负债。

用户输入金额时永远输入正数。系统根据账户方向计算。

计算公式：

```text
总资产 = 所有资产账户折算本位币金额之和
总负债 = 所有负债账户折算本位币金额之和
净资产 = 总资产 - 总负债
```

### 4.4 账户类型 Type

账户类型是系统预设的单选分类，用于默认分组和结构统计。

V1.0 资产类型：

- 银行存款
- 现金
- 股票/证券
- 基金
- 互联网钱包
- 公积金/养老金
- 其他资产

V1.0 负债类型：

- 信用卡
- 房贷
- 消费贷
- 其他负债

V1.0 不提供房产、车辆等主观估值资产类型。

### 4.5 标签 Tag

标签是用户自定义的多选分类，用于筛选和辅助统计。

示例：

- 国内
- 海外
- 工资卡
- 长期
- 流动性高
- 家庭核心
- 不常变动

### 4.6 归属 Ownership

V1.0 不做真实多人协作，但支持记录账户归属，便于家庭场景下区分账户来源。

建议预设：

- 我
- 伴侣
- 共同

V1.1 家庭协作时，归属可迁移或映射为一个或多个账户 owner。

### 4.7 月度快照 Snapshot

月度快照代表某个月的资产负债状态。

字段建议：

- `id`
- `ledgerId`
- `month`，格式如 `2026-05`
- `baseCurrency`
- `exchangeRates`
- `note`
- `completed`
- `createdAt`
- `updatedAt`

产品主线是每月一张快照，但允许补录历史月份。

### 4.8 快照明细 SnapshotEntry

快照明细是某个账户在某个月的金额记录。

字段建议：

- `id`
- `snapshotId`
- `accountId`
- `amount`
- `currency`
- `exchangeRate`
- `convertedAmount`
- `confirmed`
- `note`
- `updatedAt`

## 5. 信息架构

V1.0 建议使用 4 个主 Tab：

1. 总览
2. 快照
3. 趋势
4. 账户

设置入口放在页面右上角或账本菜单中，不单独作为主 Tab。

## 6. 页面需求

### 6.1 总览

总览是用户打开 App 后的核心看板。

需要展示：

- 当前月份。
- 总资产。
- 总负债。
- 净资产。
- 较上月变化金额。
- 较上月变化百分比。
- 本月快照完成度。
- 最近 6 或 12 个月净资产趋势。
- 资产/负债结构概览。

当本月快照未完成时，展示「继续盘点」入口。

### 6.2 快照

快照页是核心录入页面。

需要支持：

- 月份切换。
- 创建当前月份快照。
- 补录历史月份。
- 按资产/负债和账户类型分组展示账户。
- 编辑账户金额。
- 确认账户金额。
- 沿用上月金额并确认。
- 编辑账户金额备注。
- 编辑整月快照备注。

账户列表项需要展示：

- 账户名称。
- 账户类型。
- 账户币种。
- 上月金额。
- 本月金额。
- 折算本位币金额。
- 较上月变化。
- 确认状态。

快照完成规则：

- 当月所有未归档账户均确认后，快照才算完成。
- 不允许跳过单个账户。
- 如果某账户不再需要维护，应归档该账户。

### 6.3 趋势

趋势页用于长期观察资产变化。

需要展示：

- 净资产趋势。
- 总资产趋势。
- 总负债趋势。
- 月度净资产变化。
- 资产类型占比。
- 负债类型占比。

需要支持筛选：

- 按账户类型。
- 按标签。
- 按归属。

当用户修改历史月份金额后，趋势自动重算。

### 6.4 账户

账户页用于管理每月需要填写的资产和负债项目。

需要支持：

- 新增账户。
- 编辑账户名称。
- 编辑账户方向。
- 编辑账户类型。
- 编辑默认币种。
- 编辑归属。
- 编辑标签。
- 手动排序。
- 归档账户。
- 恢复归档账户。
- 按方向、类型、标签、归属筛选。

账户不做硬删除，只支持归档。

归档规则：

- 归档账户保留历史金额。
- 归档账户默认不出现在新月份快照清单。
- 归档账户仍可在历史快照和账户管理页查看。
- 归档账户可以恢复。

### 6.5 设置

设置入口包含：

- 账本名称。
- 本位币，默认 CNY。
- iCloud 同步状态。
- Face ID 锁。
- 汇率设置。
- 标签管理。
- 归档账户。
- 数据导出。
- 隐私说明。
- 关于月余。

## 7. 核心业务规则

### 7.1 新月份快照

创建新月份快照时：

- 包含所有未归档账户。
- 默认复制上月金额。
- 所有账户状态为未确认。
- 用户需要逐项确认。
- 所有账户确认后，该月快照完成。

如果没有上月快照：

- 账户金额默认为 0。
- 所有账户状态为未确认。

### 7.2 新增账户

任意用户可以新增账户。V1.0 实际为单人使用，V1.1 家庭协作时该规则继续保留。

新增账户后：

- 新账户进入当前月份和未来月份的快照清单。
- 所有历史月份中，该账户金额默认为 0。
- 所有历史月份中，该账户状态默认为已确认。
- 历史月份的完成状态不被破坏。
- 账户 owner 可以修改过去月份金额。
- 修改历史金额后，汇总和趋势自动重算。

### 7.3 修改历史金额

用户可以修改历史月份账户金额。

修改后：

- 当月总资产、总负债、净资产重新计算。
- 所有关联趋势图重新计算。
- 记录该快照或明细的最后更新时间。

V1.0 不做完整审计日志。

### 7.4 金额输入

输入规则：

- 资产和负债均输入正数。
- 账户方向决定计算方式。
- 金额默认为账户币种。
- 金额支持小数。
- 可考虑支持中文金额单位输入，例如 `12.3万` 自动识别为 `123000`。

### 7.5 显示规则

- 资产使用资产视觉样式。
- 负债使用负债视觉样式。
- 净资产为正和为负时可使用不同视觉样式。
- 原币金额和本位币折算金额均应可见。

## 8. 多币种与汇率

### 8.1 本位币

- 每个账本有一个本位币。
- V1.0 默认本位币为 CNY。
- 汇总页统一按本位币展示。
- 账户原币金额保留。

### 8.2 汇率来源

V1.0 建议使用公开汇率接口作为默认汇率来源，例如 Frankfurter。

原则：

- 自动汇率只用于估值展示，不用于交易结算。
- 月度快照不需要实时汇率。
- 每张快照保存当时使用的汇率表。
- 历史快照不因未来汇率变化而自动改变。

### 8.3 手动覆盖

用户可以手动修改某个月某个币种的汇率。

修改后：

- 该月相关账户折算金额重新计算。
- 总资产、总负债、净资产重新计算。
- 趋势自动重算。

### 8.4 汇率缓存

- 汇率应缓存到本地。
- 同一月份同一币种不应频繁请求。
- 网络不可用时，允许使用最近一次可用汇率，并提示用户。

## 9. 隐私、安全与同步

### 9.1 隐私原则

- 产品方不保存用户资产数据。
- 产品方不提供自建资产数据后端。
- 用户数据存储在设备本地和用户自己的 iCloud 中。
- 不连接银行、券商或支付账户。
- 不采集交易流水。

### 9.2 iCloud 私有同步

V1.0 使用 iCloud 私有同步。

目标：

- 用户同一 Apple ID 下的设备可以同步数据。
- 不需要注册产品账号。
- 用户资产数据不经过产品方服务器。

### 9.3 Face ID 锁

V1.0 支持 Face ID 锁。

规则：

- 用户可在设置中开启或关闭。
- 开启后，进入 App 或从后台恢复时需要验证。
- 设备不支持 Face ID 时使用系统可用的生物识别或设备密码能力。

## 10. 数据导出

V1.0 支持导出，不支持导入。

### 10.1 CSV 导出

CSV 用于用户在 Excel、Numbers 或其他表格工具中查看。

建议至少支持：

- 快照汇总导出。
- 快照明细导出。
- 账户列表导出。

### 10.2 JSON 导出

JSON 用于完整备份和未来迁移。

需要包含：

- 账本信息。
- 账户。
- 标签。
- 快照。
- 快照明细。
- 汇率表。

### 10.3 导入

V1.0 不做导入。

原因：

- 导入需要处理字段映射、币种、账户匹配、重复数据、错误恢复等问题。
- V1.0 优先确保核心记录体验稳定。

## 11. 家庭协作规划

V1.1 目标是支持真正的家庭协作。

### 11.1 协作目标

- 创建者可邀请伴侣或家庭成员加入账本。
- 所有成员可以查看所有账户和快照。
- 只有账户 owner 可以编辑该账户金额。
- 共同账户的任意 owner 可以编辑。

### 11.2 权限规则

规划权限：

- 所有成员可以查看账本总览。
- 所有成员可以查看所有账户明细。
- 所有成员可以新增账户。
- 账户 owner 可以编辑该账户在任意月份的金额。
- 共同账户的任意 owner 可以编辑。
- 账户 owner 或管理员可以归档账户。
- 管理员可以邀请或移除成员。
- 管理员可以修改账本设置。

### 11.3 技术方向

优先考虑 CloudKit Sharing。

原因：

- 符合隐私定位。
- 不需要自建账号系统。
- 适合 Apple 生态内的家庭协作。

需要后续重点评估：

- 共享邀请流程。
- 冲突处理。
- 成员身份映射。
- owner 权限在 CloudKit 共享数据中的落地方式。
- 成员移除后的数据访问边界。

## 12. 待确认问题

以下问题不阻塞 V1.0 PRD，但需要在设计或开发前进一步确认：

- V1.0 是否支持 `万` 输入。
- 默认展示最近 6 个月还是 12 个月趋势。
- 汇率接口的最终选择和兜底策略。
- CSV 导出的具体字段格式。
- Face ID 锁的触发时机。
- 账户类型是否允许用户自定义。
- 标签管理是否支持合并和重命名。
