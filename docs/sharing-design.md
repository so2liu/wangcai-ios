# 旺财 · 家庭共享体验设计

> 状态：讨论中。只记已对齐的方案，后续改代码以此为准。
> 最后更新：2026-06-21

## 核心场景

月底夫妻各自更新自己名下账户余额，再一起看家庭净资产涨跌。重心是「分工盘点 + 共同查看」，不是实时协作。

## 成员

- 成员 = 会登录、会录入的人，支持多人（典型 2 人）。
- 孩子压岁钱、代管父母账户等用账户标签表达，不做成成员。

## 归属（两个独立维度）

- **归属**：账户绑定到具体成员 或 共同。界面再翻译成「我的 / TA的 / 共同」。
  - 共同财产（房产、房贷、家庭基金）用独立的「共同」归属，不塞给个人。
  - 同名账户（如两人各有招行卡）靠归属不同成员区分，可加昵称辅助。
- **负责人**：账户可指定每月由谁更新，让各人盘点清单清爽。

## 查看

- 总览按 我的 / TA的 / 共同 三栏，家庭净资产 = 三栏之和。
- 看个人时共同部分单独列一栏，不做 50/50 拆分。
- 新成员加入即可看全部历史。

## 成员离开

- 人走数据留，绝不连带删除其录入的账户与历史。
- 其负责账户转交他人或转为只读历史。

## 邀请加入

- 不做独立账号，复用 iCloud 身份（前提：双方 iPhone + 登录 iCloud）。
- 发起人生成分享卡（AirDrop / 微信 / 二维码）→ 家人打开直接进家庭 → 认领自己的账户。

## 对单机版的影响

- 现在就能落地账户的「归属 + 负责人」标签，将来加入家庭时「我的」自动归到本人名下，不丢不重标。

## 待定

- 盘点提醒：推送催办 vs 仅 App 内被动显示。
- 同账户被两人都改：谁后改算谁 vs 提示选择。
- 是否能看到对方账户具体金额：全透明 vs 仅贡献汇总数。
- 管理权：人人平等 vs 设户主。
- 技术方案：CKShare / 自建后端 / 先做单人多设备。
