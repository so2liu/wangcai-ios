# 月度提醒与快照时间戳

## 1. 背景与目标

### 1.1 问题
当前快照只记录到"月份"粒度，但同一个月内不同日期的资产差异很大（发薪日、扣房贷、信用卡还款等都会造成突变）。用户需要主动选择一个"代表性时刻"来记录，且应用需要主动提醒，否则容易忘记。

### 1.2 目标
- 用户能配置每月固定一天 + 固定时刻接收本地通知。
- 快照能记录精确的时间戳，便于回顾"这次快照是在哪一天的什么状态下记的"。
- 错过提醒不会丢失当月记录的可能性。

### 1.3 非目标
- 不支持多条提醒规则（如双周快照）。
- 不支持服务端推送（仅本地通知）。
- 不支持"补填某个历史月份"的复杂逻辑（仅当月）。

## 2. 用户故事

- 作为用户，我可以在设置里配置"每月 25 号 20:00 提醒我"。
- 到了 25 号 20:00，我收到 iOS 通知"该记录本月资产了"，点击直接进入本月快照填写页。
- 如果我那天没空，26 号补填也行，应用记录的"快照时间"就是 26 号实际填写的时刻。
- 在趋势页 / 历史页，我能看到每条月度记录旁边的实际填写日期。

## 3. 功能详述

### 3.1 提醒配置（设置页新增"快照提醒"区块）

**字段**：
- 开关：是否启用提醒（默认关闭，首次使用引导启用）。
- 日期：每月第几号（1–28，或"每月最后一天"）。
- 时刻：时:分（默认 20:00）。

**行为**：
- 启用时若未授权通知，触发 iOS 系统权限请求；用户拒绝则提示"已保存配置，但因无通知权限不会触发提醒，可在系统设置中开启"，开关保持开启状态（用户授权后立刻生效，无需重新配置）。
- 修改任意字段后，立即重新注册下一次本地通知。

### 3.2 通知内容与跳转
- 标题：旺财
- 正文：该记录本月资产快照啦
- 点击通知 → 打开 App → 直接进入"本月快照填写页"（即当月的 SnapshotView）。若该月快照尚未创建，自动创建。

### 3.3 快照时间戳

**数据模型变更**：
- `Snapshot` 新增字段 `snapshotDate: Date`（必填，默认值为创建/更新时的当前时间）。
- `month: String` 字段保留（用作"哪个月份"的索引键，仍保证一月一条）。

**写入语义**：
- 用户首次进入某月快照页 → 创建 `Snapshot` 时，`snapshotDate = Date()`。
- 用户后续在同月内每次保存编辑 → `snapshotDate` 都更新为当前时间（即"最后一次确认资产状况的时刻"）。

**展示**：
- 历史列表 / 趋势页数据点：除月份外，副标题显示实际记录日期，如 "2026-05 · 5 月 26 日记录"。
- 趋势图横轴仍按月对齐，不受具体日期影响。

### 3.4 错过提醒的处理
- 通知是一次性的；若用户当天未点击，仅本月这一次通知消失，不重复弹。
- 用户随时可手动进入 App 填写当月快照，行为与点击通知后完全一致。
- 不展示"原定 X 号 / 实际 Y 号"对比，仅显示实际填写日期。

### 3.5 边界情况
- **本月已经填过**：本月不再触发提醒。判定标准为当月存在 `Snapshot` 且 `completed == true`。下一次提醒调度到下个月的提醒日。
  - 若用户当月已完成后又重新打开未完成（completed 改回 false），不在本月内补发通知；只在下一次自然调度周期生效。
- **月末日期不存在**：选 "每月最后一天" 时按当月实际天数（28/29/30/31）。
- **时区**：使用设备本地时区，跨时区移动设备时不做迁移补偿。
- **后台通知调度策略**：每次以下事件发生时，重新计算"下一次应触发的时刻"并注册一条本地通知（取消旧的）：
  - 用户修改提醒配置。
  - 用户保存快照（completed 状态变化）。
  - App 启动 / 进入前台。

## 4. 数据迁移
- 老快照的 `snapshotDate` 字段缺失 → 迁移时填充为 `createdAt` 的值（兜底使用 `month` 月份的 1 号 00:00）。
- iCloud 同步：新字段需加入 CloudKit schema。

## 5. 权限与隐私
- 仅请求 `UNUserNotificationCenter` 权限，不涉及远程通知 / APNs。
- 通知配置随 iCloud 同步（让用户换设备后保留设置）。

## 6. 验收标准
- [ ] 设置页可配置开关 / 日期 / 时刻并持久化。
- [ ] 启用提醒会请求并响应通知权限结果。
- [ ] 配置变更后，下一次本地通知按新配置触发。
- [ ] 点击通知能正确跳转到本月快照页。
- [ ] 新建快照时正确写入 `snapshotDate`，每次保存编辑也更新 `snapshotDate`。
- [ ] 历史 / 趋势页正确显示实际记录日期。
- [ ] 当月 `completed == true` 后不再触发本月提醒，下月正常触发。
